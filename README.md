# Overview
This repository documents my journey through the 100 Days of Data Structures and Algorithms Challenge.
I started this challenge to build consistency, strengthen my problem-solving skills, and become more confident with core DSA concepts. Instead of solving problems randomly, I’m following a structured path and committing to coding every single day.

# Challenge Goals
- Solve DSA problems daily for 100 days
- Improve problem-solving speed and accuracy
- Master core data structures and algorithms
- Prepare for coding interviews and competitive programming

Over these 100 days, I’m focusing on mastering important topics like:
DSA fundamentals
- Introduction & Basics  
- Linked Lists  
- Stack & Queue  
- Trees & Binary Trees  
- Hashing & Graphs  
- Sorting & Searching  
- And more structured topics as the days progress
